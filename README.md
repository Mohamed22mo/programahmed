# برنامج أحمد - Android WebApp APK Project

مشروع أندرويد متكامل لتحويل الموقع **http://programahmed.ifree.page/index.php** إلى تطبيق أندرويد APK بصيغة جاهزة للبناء.

---

## 🚀 طريقة الحصول على ملف APK بسهولة (3 خيارات):

### 1. الطريقة السحابية الأسهل والأسرع (بدون تثبيت برامج - مجاناً 100%):
1. قم بإنشاء مستودع جديد (Repository) على موقع [GitHub](https://github.com).
2. قم برفع محتويات هذا المجلد بالكامل إلى المستودع.
3. توجه إلى تبويب **Actions** في مستودعك، ستجد مهمة "Build Android APK" تعمل تلقائياً.
4. خلال دقيقة واحدة، ستجد ملف الـ **APK جاهزاً للتحميل المباشر** على هاتفك من قسم **Artifacts**!

---

### 2. البناء عبر برنامج Android Studio على حاسوبك:
1. حمّل وافتح برنامج **Android Studio**.
2. اختر **Open an Existing Project** وحدد هذا المجلد.
3. انتظر ثوانٍ لاكتمال مزامنة Gradle.
4. اضغط من القائمة العلوية على:
   **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
5. سيظهر لك إشعار يتيح لك فتح مكان ملف الـ APK وتثبيته مباشرة على أي جهاز أندرويد!

---

### 3. تحويل فوري عبر منصات Cloud APK:
- يمكنك استخدام **PWABuilder** أو **AppsGeyser** أو **Web2App** برابط موقعك:
  `http://programahmed.ifree.page/index.php`
